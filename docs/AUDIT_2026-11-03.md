# BUSINESS-OS Audit — 2026-11-03

Evidence: repo `UthieZz/BUSINESS-OS` @ main (post Add/Edit UI).

## Severity ranking

### Critical (fixed this pass)
1. **Firestore path segments** — `collection(db, "tracker/currentCycle/vault")` is invalid in modular SDK. Must be `collection(db, "tracker", "currentCycle", "vault")`. PATHS now arrays; service spreads them.
2. **Firebase empty-config crash** — `initializeApp({})` on import with no env. Guarded; `isFirebaseConfigured`; service throws clear error on use.
3. **Inventory engine setState(Promise)** — `getTotals()` was not awaited → processor state held a Promise. Fixed async + offline fallback.
4. **Processor listener leak** — `on()` never unsubscribed; App re-bound on refresh deps. Added `off()` + unsubscribe return from `on()`.

### High (partially fixed / remaining)
5. **Dashboard non-reactive** — was one-shot `getState`. Now subscribes to `stateChanged`.
6. **Dual vault UI** — App.jsx owns live CRUD; InventoryView is parallel and unused by App routing. Drift risk. Prefer single surface or route InventoryView from App.
7. **No Auth + client Firestore** — when env is live, security is 100% Firestore rules. Rules not in repo. Accept for private single-operator; block public deploy until rules + auth exist.
8. **Stale package-lock** — lockfile is tiny/pre-firebase. Local `npm install` required to regenerate.

### Medium
9. **Header theme drift** — was #181818 / green-500. Aligned to Cyber-Obsidian.
10. **`.env` not ignored** — only `*.local`. Added `.env` / `.env.*`.
11. **Full collection scans** — client-side search/filter. Fine for small vault; will need indexes/queries at scale.
12. **StrainBrain** — hard-coded noise, always mounted under Processor. Not harmful; not product.
13. **confirm() deletes** — blocks mobile; replace with inline confirm later.

### Low / deferred
14. No ErrorBoundary, no offline queue, no tests, no CI.
15. Sales / investors / drop_requests paths defined but no services.
16. Mobile Sidebar always 240px — no collapse drawer.

- Do not invent Realtime Database or new roots.
- Do not expand StrainBrain into features without a product decision.
